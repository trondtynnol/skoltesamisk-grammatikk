#### Pre- og postposisjoner og nomen

Pre- og postposisjoner styrer kasuset på nomenet de hører sammen med. De aller fleste pre- og postposisjoner styrer genitiv, for eksempel:

- Ståkkan lij pååʹrd âʹlnn.
{% comment %} glass.\textsc{nominativ} være.\textsc{pres.ent.3p} bord.\textsc{ent.genitiv} på {% endcomment %}
- «Glasset er på bordet.»

### Relativsetninger

### Nekting

På norsk er nektingsordet «_ikke_» et adverb, det modifiserer setninga uten å bøyes sjøl. På skoltesamisk nekter man derimot ved å bruke et eget nektingsverb som skal samsvarsbøyes med subjektet. Etter nektingsverbet står hovedverbet i en egen nektingsform, som også kalles konnegativ. Se kapittelet Bøyingslære om hvordan denne dannes og nærmere om bøying av nektingsverbet.

#### Presens

I nektende setninger er det altså nektingsverbet som samsvarsbøyes, mens nektingsforma av hovedverbet er lik for de fleste personer.

- Mon jiõm poor huutt.
{% comment %} jeg.\textsc{nominativ} \textsc{neg.ent.1p} spise.\textsc{konneg} grøt.\textsc{ent.akkusativ} {% endcomment %}
- «Jeg spiser ikke grøt.»

- Ton jiõk poor huutt.
{% comment %} du.\textsc{nominativ} \textsc{neg.ent.2p} spise.\textsc{konneg} grøt.\textsc{ent.akkusativ} {% endcomment %}
- «Du spiser ikke grøt.»

- Son ij poor huutt.
{% comment %} hen.\textsc{nominativ} \textsc{neg.ent.3p} spise.\textsc{konneg} grøt.\textsc{ent.akkusativ} {% endcomment %}
- «Hen spiser ikke grøt.»

- Mij jeäʹp poor huutt.
{% comment %} vi.\textsc{nominativ} \textsc{neg.flt.1p} spise.\textsc{konneg} grøt.\textsc{ent.akkusativ} {% endcomment %}
- «Vi spiser ikke grøt.»

- Tij jeäʹped poor huutt.
{% comment %} dere.\textsc{nominativ} \textsc{neg.flt.2p} spise.\textsc{konneg} grøt.\textsc{ent.akkusativ} {% endcomment %}
- «Dere spiser ikke grøt.»

- Sij jie poor huutt.
{% comment %} de.\textsc{nominativ} \textsc{neg.flt.3p} spise.\textsc{konneg} grøt.\textsc{ent.akkusativ} {% endcomment %}
- «De spiser ikke grøt.»

I den såkalla fjerde personen (og i visse imperativformer, se nedenfor) brukes derimot en annen nektingsform, kalt konnegativ II.

- Jeät porru huutt.
{% comment %} \textsc{neg.4p} spise.\textsc{konnegII} grøt.\textsc{ent.akkusativ} {% endcomment %}
- «Man spiser ikke grøt.»

#### Imperativ

Nektingsverbet har egne imperativformer. Etter andre person entall bruker man vanlig nektingsform av hovedverbet, etter andre person flertall enten vanlig nektingsform eller konnegativ II, og etter alle andre former konnegativ II.

{% comment %} \textsc{neg.imp.ent.2p} spise.\textsc{konnegII} grøt.\textsc{ent.akkusativ} {% endcomment %}

- Jeälas porru huutt.

### Habitiv – det å ha noe

Skoltesamisk har ikke noe eget verb for _å ha_. I stedet brukes verbet _leeʹd_ »å være» i en egen konstruksjon kalt habitiv. Den er bygd opp slik:

\begin{itemize
	\item Eieren / den som har noe bøyd i lokativ kasus.
	\item _leeʹd_-verbet bøyd i tredje person entall eller flertall.
	\item Det man har bøyd i nominativ kasus (grunnform).
\end{itemize

I slike setninger regnes det man har – ikke den som har noe – som det grammatiske subjektet, og derfor bøyes verbet i tall etter dette, for eksempel:

- Muʹst lij villj.
{% comment %} jeg.\textsc{lokativ} være.\textsc{presens.ent.3p} bror.\textsc{ent.nominativ} {% endcomment %}
- «Jeg har en bror.»

- Muʹst lie viillj.
{% comment %} jeg.\textsc{lokativ} være.\textsc{presens.flt.3p} bror.\textsc{flt.nominativ} {% endcomment %}
- «Jeg har brødre.»

Hvor mange som har noe påvirker derimot ikke verbbøyinga:
- Meeʹst lij villj.
{% comment %} vi.\textsc{lokativ} være.\textsc{presens.ent.3p} bror.\textsc{ent.nominativ} {% endcomment %}
- «Vi har en bror.»

- Meeʹst lie viillj.
{% comment %} vi.\textsc{lokativ} være.\textsc{presens.flt.3p} bror.\textsc{flt.nominativ} {% endcomment %}
- «Vi har brødre.»

- Neezznest lij autt.
{% comment %} kvinne.\textsc{ent.lokativ} være.\textsc{presens.ent.3p} bil.\textsc{ent.nominativ} {% endcomment %}
- «Kvinna har en bil.»

- Neezznin lij autt.
{% comment %} kvinne.\textsc{flt.lokativ} være.\textsc{presens.ent.3p} bil.\textsc{ent.nominativ} {% endcomment %}
- «Kvinnene har en bil.»

_leeʹd_-verbet kan naturligvis også bøyes i andre tidsformer enn presens, slik som preteritum og perfektum.
- Meeʹst leäi villj.
{% comment %} vi.\textsc{lokativ} være.\textsc{preteritum.ent.3p} bror.\textsc{ent.nominativ} {% endcomment %}
- «Vi hadde en bror.»

- Meeʹst leʹjje viillj.
{% comment %} vi.\textsc{lokativ} være.\textsc{preteritum.flt.3p} bror.\textsc{flt.nominativ} {% endcomment %}
- «Vi hadde brødre.»

- Neezznest lij leämmaž autt.
{% comment %} kvinne.\textsc{ent.lokativ} være.\textsc{presens.ent.3p} være.\textsc{perf.part} bil.\textsc{ent.nominativ} {% endcomment %}
- «Kvinna har hatt en bil.»

- Neezznin lie leämmaž aaut.
{% comment %} kvinne.\textsc{flt.lokativ} være.\textsc{presens.ent.3p} være.\textsc{perf.part} bil.\textsc{flt.nominativ} {% endcomment %}
- «Kvinnene har hatt biler.»

I nektende habitivssetninger er det nektingsverbet som skal samsvarsbøyes med det man har, mens _leeʹd_-verbet står i den faste nektingsforma _leäkku_.

- Muʹst ij leäkku villj.
{% comment %} jeg.\textsc{lokativ} \textsc{neg.ent.3p} være.\textsc{konneg} bror.\textsc{ent.nominativ} {% endcomment %}
- «Jeg har ikke en bror.»

- Muʹst jie leäkku viillj.
{% comment %} jeg.\textsc{lokativ} \textsc{neg.flt.3p} være.\textsc{konneg} bror.\textsc{flt.nominativ} {% endcomment %}
- «Jeg har ikke brødre.»

Man kan også her bruke de sammendradde formene av nektingsverb og _leeʹd_-verb.

- Muʹst iʹlla villj.
{% comment %} jeg.\textsc{lokativ} være.\textsc{neg.presens.ent.3p} bror.\textsc{ent.nominativ} {% endcomment %}
- «Jeg har ikke en bror.»

- Muʹst jeäʹla viillj.
{% comment %} jeg.\textsc{lokativ} være.\textsc{neg.presens.flt.3p} bror.\textsc{flt.nominativ} {% endcomment %}
- «Jeg har ikke brødre.»
